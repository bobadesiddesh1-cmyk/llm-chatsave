# LinkedIn launch post — Threadkeeper

## Post copy (paste-ready)

I've closed a ChatGPT tab and immediately regretted it more times than I'd like to admit.

So I built the fix.

**Threadkeeper** is a Chrome extension that exports any ChatGPT, Claude, or Gemini conversation to Markdown, PDF, or HTML — one click, formatting intact. Code blocks, tables, images, all of it.

A few things I cared about while building it:

→ Bulk export — select your whole history, get one ZIP
→ Pick your scope — full thread, just your prompts, or just the AI's replies
→ 100% local — no account, no server, no data collected. Ever.
→ Works the moment you install it — even on tabs you already had open

That last point mattered more than I expected. Every extension I looked at wanted an account before it would export a single file. This one doesn't get an account to want.

It's live on the Chrome Web Store now. 30-second demo below.

If you're a consultant handing off AI research as a deliverable, a researcher archiving sessions, or just someone who's lost a conversation they needed — this is for you.

Would love feedback if you try it. 🧵
